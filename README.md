Datasets associated to the paper: "Analysis and evaluation of the electric vehicle charging network in Spain using spatial point pattern analysis".

CCAA_totales.csv: data about Autonomous Communities.

electrolineras2.csv: data about geolocation of EV charging stations in Spain (2025).

gasolineras2.csv: data about fuel stations in Spain (2025).

matriz_correlacion.csv: correlacion between variables at the Autonomous Communities scale.
